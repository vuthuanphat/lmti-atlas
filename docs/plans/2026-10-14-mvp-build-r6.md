# MVP build continuation — r6

The owner requested building the MVP before connecting live clients/providers,
and will arrange an independent operator after the build is ready. The master
plan now records that order. Live acceptance remains required for release and
cutover; it is no longer an implementation dependency for M2/M3.

## Delivered in this continuation

The native owner can export a v2 declared reference projection in one read-only
transaction. The Agent can opt in to repository/knowledge inventory, identity
lookup and typed component associations. Labels are classification-aware;
locators and stored fingerprints are withheld. Opaque binding fingerprints
invalidate a cursor after reference edits, even without a revision change.
Content is explicitly unloaded, not treated as analyzed code or a verified
document. The v1 snapshot/default launch remains compatible.

See the [reference ADR](../adr/2026-10-14-agent-reference-projection.md).

Package: `build/studio-mvp-r6-20261014`, built from the freshly installed
`build/studio-agent-references-native-20261014`. It contains the existing web
presentation and the new opt-in SDK capability; the Structure web page has not
yet been expanded by this slice. Existing launchers/packages remain preserved.

## Remaining MVP build work

Connect compiled code/document/memory projections through their owners with
explicit identity mappings and source versions; add the integrated structure,
source and reviewed-proposal web workflow; implement the scoped read-only
observation adapter and freshness/error states against controlled test sources;
then package and exercise the complete operator/Agent path. These are required
build items, not deferred merely because reference inventory now passes.

Live Cursor/provider/IoT proof, independent operator and clean Windows are later
acceptance work under the owner's instruction. No new live connection, cloud
model turn, device action, publication or `.lmti` write occurred.

Safe lesson candidate: keep reference identity and loaded-content authority
separate; an owner association or digest is not evidence of current source
content or permission to fetch it.
