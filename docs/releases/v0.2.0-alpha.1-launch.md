# LMTI v0.2.0-alpha.1 — Launch drafts

These messages are drafts for use only after runtime release acceptance and
publication. Do not post the announcement while the release is still a draft.

## Release introduction

LMTI v0.2.0-alpha.1 brings a **React + Vite local browser workspace** to LMTI's
project-memory and context tools. A local Node.js API connects the interface
to native C++/SQLite and Python owners. React + Vite is the sole product UI;
Qt Core/Sql remains a backend dependency.

Explore project structure, inspect the sources behind context, and review
proposals before changes are applied. Start with a sample project and help
improve setup, scope clarity and review workflows.

This alpha targets Windows x64 and requires Node.js 24+ x64, Python 3.11+ x64
and the compatible Microsoft C++ runtime. Node and Python are not bundled.
APIs and storage contracts can change. Read the
[release notes](v0.2.0-alpha.1.md) and [QA summary](v0.2.0-alpha.1-qa.md)
for backup instructions, validation scope and known limitations.

## GitHub Discussion

Title: Try LMTI v0.2.0-alpha.1: local project context for coding agents

LMTI v0.2.0-alpha.1 is available as a Windows x64 public alpha.

The idea is practical: give coding agents scoped project understanding that you
can inspect. The React + Vite workspace brings together project structure,
reviewed summaries, eligible memory and evidence on your machine.

We are looking for feedback on three things:

1. Can you get a sample project running from the setup guide?
2. Is the source and scope of a context response clear?
3. Where does proposal review become confusing?

Get the release at
https://github.com/vuthuanphat/lmti-atlas/releases/tag/v0.2.0-alpha.1
and read the limitations before using existing data. External AI clients and
providers retain their own permissions and data handling.

For bug reports, include prerequisite versions and reproducible steps without
private project data or session URLs. Report vulnerabilities through the
private channel in SECURITY.md.
