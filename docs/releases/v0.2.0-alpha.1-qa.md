## Protection and distribution

SQLite is unencrypted and nonsecret-only. DPAPI protects specific client
backups/journals and writer coordination, not the domain databases. There is no
OS sandbox or multi-user authorization service. No shell/SQL/path HTTP tool,
Agent write permission, device command or silent migration was added.
Source folders/databases survive library reference removal. New bindings require
relaunch; library management never expands a running session's project access.

Keep `.gitignore` configured before every push. Operational `.lmti/`, credentials,
databases and session material are excluded. Secret scans must review any new
finding privately; existing synthetic sentinels are not grounds to suppress rules.
Qt Core/Sql notices and corresponding source remain required. Manifest checksums
are integrity evidence, not a publisher signature. Node/Python remain external
trusted prerequisites. The browser runtime contains fixed owner bundles, not the
unrestricted source CLI.
